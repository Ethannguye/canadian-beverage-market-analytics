# Original CIMT exports

Upload original, unedited CSV/Excel files downloaded from the Statistics Canada Canadian International Merchandise Trade Web Application here. Suggested naming: `HS220210_imports_2020_2025.csv`, `HS220299_imports_2020_2025.csv`, etc. Do not manually alter source data. Scripts will clean and normalize a copy for analytical use. If a file exceeds GitHub browser's 25 MiB per-file limit, do not split it arbitrarily; report its size first so we can choose a large-file storage method.

Source: https://www150.statcan.gc.ca/n1/en/catalogue/71-607-X2021004
